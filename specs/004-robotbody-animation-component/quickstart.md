# Quickstart: RobotBody Animation Verification

**Goal**: Verify the visual fidelity and performance of the RobotBody component.

## Prerequisites
- [ ] Local development environment running (`npm start` in `frontend/`).

## Verification Steps

### 1. Visual Fidelity
- [ ] Open the homepage.
- [ ] **Structure**: Do you see a humanoid grid layout (Head, Torso, Limbs)?
- [ ] **Colors**: Is the background black? Are borders/pulses Neon Lime (`#BFE600`)?
- [ ] **Animation**: Do you see "energy pulses" moving along lines?

### 2. Responsiveness
- [ ] Resize to mobile width.
- [ ] Does the grid stack or scale down without horizontal scroll?
- [ ] Does it look broken or overlapping?

### 3. Performance & Stability
- [ ] Refresh the page. Any "Hydration failed" errors in console?
- [ ] Run a Lighthouse check. Is Performance still >90?
