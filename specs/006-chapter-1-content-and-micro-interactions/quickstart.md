# Quickstart: Chapter 1 Verification

**Goal**: Verify content and interactivity of Chapter 1.

## Prerequisites
- [ ] Local development environment running (`npm start` in `frontend/`).

## Verification Steps

### 1. Content & Navigation
- [ ] Navigate to `/docs/chapter-1` (or sidebar link).
- [ ] **Structure**: Verify 4 sections exist (Transition, Triad, Hardware, Senses).
- [ ] **Visuals**: Check if 2 Mermaid diagrams are rendered.

### 2. Hardware Check
- [ ] Scroll to "Hardware Nervous System".
- [ ] Select "M2 Mac" -> Expect Red "Insufficient" warning.
- [ ] Select "RTX 4090" -> Expect Green "Ready" message.

### 3. Tooltips
- [ ] Find the term "SLAM".
- [ ] Hover over it (or tap on mobile).
- [ ] Verify definition overlay appears.
