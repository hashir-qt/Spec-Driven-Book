# Quickstart: Content Refinement Verification

**Goal**: Verify content depth and structure updates.

## Prerequisites
- [ ] Local development environment running (`npm start` in `frontend/`).

## Verification Steps

### 1. Hierarchy Check
- [ ] Navigate to each of the 4 pages in Chapter 1.
- [ ] Verify the first sub-heading (H2) is NOT the same as the Page Title (H1).
- [ ] Verify logical nesting (H1 -> H2 -> H3).

### 2. Component Integrity
- [ ] Go to "Hardware Nervous System".
- [ ] Does the `<HardwareCheck />` validator still work?
- [ ] Go to "Senses of the Machine".
- [ ] Do `<TermTooltip />` hovers work?

### 3. Formatting & Citations
- [ ] Check for **Bold** key terms.
- [ ] Check for Admonitions (colored boxes).
- [ ] Check citations `[1]` link to the References section.
