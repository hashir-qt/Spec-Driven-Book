# Quickstart: Preface Content Verification

**Goal**: Verify the content and structure of the new Preface page.

## Prerequisites
- [ ] Local development environment running (`npm start` in `frontend/`).

## Verification Steps

### 1. Visual Inspection (Browser)
- [ ] Navigate to `http://localhost:3000/docs/preface` (or configured route).
- [ ] **Check Sidebar**: Is "Preface" (or "How to Use This Book") the very first item?
- [ ] **Check Hardware Warning**: Is the "Hardware Reality Check" section red/danger styled?
- [ ] **Check Checklist**: Is there a readable checklist at the bottom?

### 2. Content Accuracy
- [ ] Verify GPU requirement: "RTX 4070 Ti+"
- [ ] Verify RAM requirement: "64GB"
- [ ] Verify Cloud Alternative: "AWS g5.2xlarge"

### 3. Navigation Test
- [ ] Click the "Chapter 1" link at the bottom.
- [ ] Confirm it navigates to the expected next page (even if placeholder).
