# Quickstart: Visual Identity Verification

**Goal**: Verify the new "RoboLearn" aesthetic and layout.

## Prerequisites
- [ ] Local development environment running (`npm start` in `frontend/`).

## Verification Steps

### 1. Global Theme Check
- [ ] Open the homepage.
- [ ] **Dark Mode**: Is the background pure black (`#000000`)?
- [ ] **Primary Color**: Are buttons and links Lime Green (`#BFE600`)?
- [ ] **Typography**: Inspect an `H1` element. Is the font-family "Space Grotesk"?

### 2. Landing Page Layout (Desktop)
- [ ] Resize browser to >1024px width.
- [ ] **Hero Section**: Is the Text on the **Left** and Diagram on the **Right**?
- [ ] **Navbar**: Is it transparent/black (not gray)?

### 3. Responsiveness (Mobile)
- [ ] Resize browser to mobile width (e.g., iPhone size).
- [ ] **Hero Section**: Does the Text stack **above** the Diagram?
- [ ] **Legibility**: Is text readable on the small screen?
