# Quickstart: Chapter 3 Interactive Components

This document provides integration scenarios for the new interactive component being developed for Chapter 3.

## Component: `<UrdfExplorer />`

### Scenario 1: Basic Usage

This component can be embedded directly into any MDX file. It is self-contained with its own hardcoded URDF snippet and SVG.

```jsx
import UrdfExplorer from '@site/src/components/UrdfExplorer';

<UrdfExplorer />
```
