# Data Model: RAG Ingestion Engine (Backend Initialization)

This document describes the key entities and their structure as they relate to the ingestion process and storage in Qdrant.

## Entities

### Document Chunk

A semantic unit of text extracted from the Docusaurus Markdown files.

-   **Description**: A segment of the textbook content, semantically coherent, typically delimited by H2/H3 headers.
-   **Unique Identifier**: A combination of its source file path and a hash of its content. This ensures uniqueness and enables efficient detection of changes for updates/re-ingestion.

### Vector Embedding

A numerical representation of a Document Chunk.

-   **Description**: A dense vector of floating-point numbers, generated by the Google Gemini model (`models/embedding-001`). Used by Qdrant for similarity search.

### Qdrant Collection

The storage unit within Qdrant Cloud for the ingested data.

-   **Name**: `physical_ai_textbook`
-   **Description**: A named collection in Qdrant Cloud that stores both the vector embeddings and their associated metadata (payload).
-   **Structure**: Each entry in the Qdrant collection corresponds to a `Document Chunk` and will have the following properties:
    -   **`id`**: `string` - The unique identifier for the chunk (combination of `filepath` and `content_hash`).
    -   **`vector`**: `list[float]` - The vector embedding of the `Document Chunk`.
    -   **`payload`**: `object` - Metadata associated with the chunk:
        -   `content`: `string` - The actual text content of the chunk.
        -   `filepath`: `string` - The relative path to the original Markdown/MDX file (e.g., `chapter-01-foundations/01-great-transition.mdx`).
        -   `heading`: `string` (Optional) - The H2 or H3 header under which the chunk falls. If the chunk is at the top level or directly under H1, this might be `null` or derived from the title.
        -   `section_id`: `string` (Optional) - A generated ID for the section, potentially derived from slugified heading.
        -   `url`: `string` (Optional) - The relative URL path to the section in the Docusaurus site.

## API Contracts

This feature is a local ingestion script and does not expose any external APIs. Therefore, no API contracts (`contracts/` directory) are generated in this phase.
